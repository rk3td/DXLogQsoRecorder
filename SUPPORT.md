# Support

For reproducible bugs and feature requests, use GitHub Issues.

Before opening an issue:

1. Confirm that you are using the latest release.
2. Check existing issues.
3. Attach the relevant part of `Logs/recorder.log`.
4. State the Windows version, DXLog.net version, selected audio device, and application version.
5. Do not attach private contest recordings unless they are essential and safe to share.

General DXLog.net configuration questions should be checked against the DXLog.net documentation first.
